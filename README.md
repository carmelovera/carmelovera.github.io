# Carmelo Vera - Portfolio Website

My personal portfolio website: **https://carmelovera.com**

I'm a software developer based in Seattle, WA, with a Bachelor of Applied Science in Software Development from Bellevue College. This site shows my work, the projects I'm building, and how to get in touch.

## Features

- **Single-page layout with tab navigation** - tabs scroll smoothly to each section and highlight the one you're reading
- **Animated Seattle scene** - an illustrated skyline (Space Needle, Mt. Rainier, the Great Wheel, a ferry) built in SVG
- **Jimothy the raccoon** - an original SVG character who runs in, dives into a trash can and throws out "hello" in 13 languages (click him to do it again)
- **Interactive app concept** - a working UI prototype of my Time Tracker app, with categories, timers and a weekly chart
- **Responsive design** - works on desktop and mobile
- **Accessibility** - semantic HTML, keyboard-friendly controls, and support for reduced-motion preferences

## Built with

- HTML5
- CSS3 (custom properties, Grid, Flexbox, keyframe animations, media queries)
- Vanilla JavaScript (Web Animations API, IntersectionObserver)
- SVG illustrations, drawn in code
- Google Analytics 4
- Git & GitHub Pages

## How I built it

I designed and built this site with AI-assisted development, using Claude and ChatGPT as coding partners. I directed the design, content and features, reviewed and adjusted the code, and handled version control and deployment with Git and GitHub Pages.

